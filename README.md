# 🐾 Bom para Cachorro - 2023

Projeto de site institucional para pet shop fictício, com foco em boas práticas de higiene, promoções de produtos e apresentação de serviços.

## 📄 Páginas e Seções

- **Home** com dica do dia sobre cuidados com pets
- **Produtos e Promoções** (roupas, brinquedos, acessórios)
- **Serviços** como banho e tosa, veterinário, spa, táxi dog etc.
- **Contato e Localização** no rodapé
